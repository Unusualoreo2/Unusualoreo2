### Projects

- **[ClusterFlow](https://github.com/Unusualoreo2/ClusterFlow)**: Slurm job efficiency analyser that shows how much requested CPU, memory, GPU and time jobs actually used and what to request next time. Analysed 2.37 million real jobs from the IN2P3 dataset in 72 seconds. Single-file Python CLI plus a FastAPI web app, 700+ tests.
- **[Local LLM tuning](https://github.com/Unusualoreo2/local-llm-tuning)**: roofline-guided tuning of Qwen3-30B-A3B on a 16 GB AMD RX 9060 XT, from 16.4 to 107 tokens/s (6.5×), with a 19-page report.
